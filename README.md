# Meters SPA

## Пререквизиты

Для локального запуска потребуется:

- Node.js `22.x`
- npm `10.x+`


Для запуска в docker потребуется:

- Docker
- Docker Compose
- Make - опционально, для запуска через `Makefile`

---

## Переменные окружения

Создать файл `.env` в корне проекта или скопировать шаблон:

```bash
cp .env.template .env
```

Заполнить переменными:

| Переменная | Обязательная | Значение по умолчанию | Описание | Пример |
|------------|:------------:|-----------------------|----------|--------|
| `VITE_APP_API_URL` | Да | — | API URL бекенда | `http://example.com/c300/api/v4/test` |
| `VITE_APP_FE_PORT` | Нет | `5173` | Порт, на котором frontend будет доступен в Docker/при локальном запуске | `5173` |


## Запуск в docker

- Собрать и запустить контейнер - `make up`

После запуска приложение будет доступно по адресу: `http://localhost:5173`


## Локальный запуск 

- Установить зависимости - `npm ci`
- Запустить dev-сервер - `npm run dev`

После запуска приложение будет доступно по адресу: `http://localhost:5173`
